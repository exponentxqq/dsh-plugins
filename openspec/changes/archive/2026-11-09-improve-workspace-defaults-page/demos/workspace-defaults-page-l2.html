工作区默认档页面优化 · 方案速览

当前页面的问题（实测与代码核对）

  • 能力缺失：页面形态下宿主契约返回空宇宙（D-24），分组开关清单从不渲染——页面上只能看/删存量条目，无法添加默认关闭项；而面板里同一编辑器却有完整清单。
  • 信息平铺：约 8 行纯文本（key/文件/三计数/降级文案/命令提示/两句说明）以相近视觉权重纵向堆叠，无卡片无分块，主次不分。
  • 标题冗余：分节正文顶部 h3 与 tab 名「工作区默认档」重复。
  • 交互缺口：无刷新入口（只能切 tab 重挂）；命令提示是纯文本不可复制；空档时页面近乎空白。

参考「会话工具面」的思路（参考但不照搬）

  • 保留：三段式分组（MCP 服务器 / 技能 / 内置工具）、组开关 + 行开关两级粒度、组头计数摘要、保护行禁用 + 标签、残留 chip 只能移除、保存不追溯语义。
  • 超越（面板做不好、页面能做好的）：Modal 六段纵排 → 三卡分层（概要 / 清单 / 命令）；全局过滤（面板只有内置组过滤）覆盖组行/技能/内置/残留；行下描述次行 + 技能调用标签（面板无详情）；刷新入口；可复制命令块；空档/降级/无匹配三种空态。

具体优化点（交互 × 视觉）

  • 交互：A2 宿主按工作区算宇宙（清单恢复可开关，/inventory 同款归组口径）；C1 全局过滤；C3 概要卡刷新；C4 命令卡 + 复制按钮；C6 空档可视化块；两段式清空保留。
  • 视觉：B1 单列三卡（与同页「工作区文件夹」分节视觉语言对齐，bg-layer-2 卡片 + 12px 圆角）；三计数徽章化数字；登记态徽章；行下灰字描述；技能标签（模型可调 / 仅用户调用 / 来源）。

改造后页面结构

分节正文（tabpanel 内，无重复 h3） ├─ 概要卡 工作区名 + 登记/未登记徽章 + 刷新 | key · 档文件 | 清单 N · 默认关 M · 残留 K | 损坏警告 ├─ 清单卡 全局过滤框 | 开关语义提示 | 空档块(C6) │ ├─ MCP 服务器组（折叠 + 组开关 + 行开关 + 行下描述） │ ├─ 技能组（整档开关 + 行 + 调用方式/来源标签） │ ├─ 内置工具组（行 + Protected 禁用） │ ├─ 残留 chips（只能移除） │ └─ 注记：全局并集近似 · 未归组计数 · 技能观测不完整 ├─ 命令卡 目标工作区注释 + /tools workspace off 命令块 + 复制 + 边界说明 ├─ 脚注 不追溯(scope) · 并集(union) └─ 页脚 两段式清空 + 已保存提示 + 失败 alert

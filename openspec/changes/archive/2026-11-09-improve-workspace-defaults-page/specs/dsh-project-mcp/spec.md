# dsh-project-mcp 变更影响

## ADDED Requirements

### Requirement: 跨插件归属查询服务

插件 SHALL 在宿主上下文以 `projectMcp` 名发布一条只读归属查询服务，供其他插件（如工作区默认档页面）按**工作区路径**（而非某个会话）回答「该工作区配置了哪些项目级服务器」；服务随插件 fiber 卸载自动消失，消费方读到缺席时 SHALL 按「无项目级 MCP」降级。

#### Scenario: 按工作区路径读声明集合

- **WHEN** 消费方以工作区规范路径调用归属查询
- **THEN** 服务经归属器把路径解析为根集，返回该根集下的项目级服务器声明集合（claim 语义：加载中或等待重试的服务器也算本工作区配置的）

#### Scenario: 路径不被任何工作区认领时返回 null

- **WHEN** 消费方传入的路径不被任何已登记工作区的根集认领
- **THEN** 服务返回 `null`（归属失败），消费方据此采用 fail-closed 降级而不是当作空集

#### Scenario: 全量声明读数与卸载语义

- **WHEN** 消费方读取全部项目级服务器声明，或本插件 fiber 卸载
- **THEN** 全量读数返回不分工作区的声明集合；卸载后服务从上下文消失，`ctx.get('projectMcp')` 读到 `undefined`

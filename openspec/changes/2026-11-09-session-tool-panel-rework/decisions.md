## 收敛结论

- 前沿为空；未答项零（无静默假设——移交项全部标注为设计线技术决策）。
- 共识形态：**会话工具面 = 页面同款三卡 + 脚注/动作区的纯会话级面板**（概要卡：会话状态事实与计数；清单卡：全局过滤 + 共用分组清单，工具/技能/内置同卡，残留地址可开启；命令卡：会话级命令模板；动作区：两段式恢复创建时快照）；**用户级与工作区级默认档配置 GUI 全部退出会话工具面**（工作区级仍在统一配置页分节，用户级仅命令）。
- spec 修订面（落档）：`dsh-session-tool-toggle` 的「Web 配置界面（入口与构成）」「默认档编辑面的分组开关形态」「用户级默认档」「工作区默认档分节」等 requirement 及关联场景按上述共识重写。

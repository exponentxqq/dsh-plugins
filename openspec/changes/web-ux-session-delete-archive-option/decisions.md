## 裁定依据与结论

- Q1：菜单不变挤；「归档到目录」独立菜单项会与既有「归档会话」（工作区归档集合
  archive/unarchive）撞名混淆——单入口 + 框内单选把区分交给文案与警示区。
- Q2：「比如 ~/.dsh/archive/sessions」暗示路径意图可变；预览响应带宿主解析后的真实
  目标路径，UI 展示真实去向，避免 config 改动后 UI 显示错路径。
- Q3：会话 id 虽全局唯一，但恢复时需知道源项目目录才能搬回原位；投影缓存是
  `storages/session_projcache/` 纯缓存，迁移无收益。
- Q4：`~/.dsh` 可能独立挂载，EXDEV 是常态而非边缘；与既有删除失败语义同构降低认知成本。
- Q5：用户明确选择保守方向——不可逆操作（物理删除）必须主动选择。
- Q6：触碰 sessionPersistence 导入面会显著扩大范围，另开变更。
